How a request flows

Every answer is built from live database queries

  1. You ask in plain English in the agent bar at the top of any page.
  2. The orchestrator plans and hands each part of the request to the right specialist: Inventory, Procurement or Analytics.
  3. Specialists call tools: 13 typed functions that query the warehouse database for stock, suppliers, demand and purchase orders.
  4. The orchestrator combines the results into one answer and shows which agents and tools were used.
  5. You stay in control: agents can only draft purchase orders, and a person approves each one before it is sent.
